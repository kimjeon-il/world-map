## 검증 기준

- 모든 fragment는 `hydro-system:<MAIN_RIV>` ID와 `mainstem` 또는 `tributary` 역할을 가집니다.
- 본류와 지류가 함께 표시되는 수계 458개에서 두 역할이 같은 논리 ID로 결합됐습니다.
- 표시 강의 미해결 육지 종점은 0개입니다. 바다·호수·합류점·내륙 유역으로 설명되지 않는 원본 terminal을 가진 수계는 안전하게 제외했습니다.
- 국경하천은 전체 reach가 아니라 10km 이상 연속되는 적합 구간만 진입점·이탈점에서 분할해 Natural Earth 공유국경 좌표로 교체했습니다.
- 국가 데이터는 258개, 원본 국경 좌표는 548,471개로 유지됩니다.
- manifest와 index는 각각 100KiB 미만이며 전체 압축 수계 자산은 48MiB 제한을 통과합니다.
