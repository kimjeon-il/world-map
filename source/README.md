# ChronoMap Editor — MVP 0.3 Offline

역사·대체역사·국가운영 시뮬레이션용 지도 편집기 프로토타입입니다.

이번 버전의 핵심 변경점은 **지구본과 기본 국가 경계를 앱 자체에 내장**한 것입니다. 인터넷에서 지도 스타일, 국가 GeoJSON, 지도 엔진을 받아오지 않습니다.

## 실행 방법

압축을 푼 뒤 **`index.html`을 더블클릭**하면 됩니다.

별도의 설치, Python 서버, Node.js, 인터넷 연결이 필요하지 않습니다.

브라우저의 로컬 파일 정책 때문에 저장 동작이 제한되는 특수한 환경에서는 아래처럼 로컬 서버로 열어도 되지만, 기본 사용법은 더블클릭 실행입니다.

```bash
python -m http.server 8080
```

## 완전 내장된 항목

- 지도 렌더링 엔진: 로컬 D3.js v3.5.6
- 3D 지구본 투영
- 2D 평면 투영
- 기본 세계 국가 경계 177개
- 위·경도 격자
- 국가명 라벨
- 편집 UI 및 저장 기능

앱 실행 중 외부 지도 서버나 CDN에 연결하지 않습니다.

## 현재 구현된 기능

- 3D 지구본 / 2D 평면 즉시 전환
- 지구본 드래그 회전, 평면지도 드래그 이동
- 마우스 휠 확대·축소
- 국가 클릭 선택
- 국가별 국명, 색상, 수도, 메모, 국기 등록
- 국가 / 사용자 도형 / 도시·지명 / 국가명 라벨 표시·숨김
- 국가 선택 잠금
- Point / LineString / Polygon 직접 작성
- 작성한 선·폴리곤의 꼭짓점 드래그 편집
- 사용자 도형 이름·분류·색상·메모 저장
- 도시·지명 직접 추가·이동·편집·삭제
- 발칸 빠른 이동 / 세계 보기
- 프로젝트 자동저장(LocalStorage)
- 프로젝트 JSON 저장·불러오기
- GeoJSON 가져오기·내보내기
- Undo / Redo 최대 100회
- 버튼 클릭 피드백, 현재 도구, 마지막 동작 표시

## 기본 지도 해상도

내장 국가 경계는 **세계 전체를 빠르게 표시하기 위한 저해상도 기본 데이터**입니다. 세계/대륙/국가 단위 작업을 시작하기에는 적합하지만, 마을·산줄기·세밀한 역사 국경을 그대로 따기 위한 데이터는 아닙니다.

발칸 민족분포도처럼 매우 세세한 작업은 별도의 고해상도 GeoJSON을 가져오거나 이후 추가할 고밀도 편집 레이어를 사용하는 구조로 확장합니다.

## 기본 조작

1. `지구본` 상태에서 드래그 → 지구 회전
2. 국가 클릭 → 오른쪽에서 국명·색상·수도·국기 등 수정
3. `폴리곤` → 지도에 꼭짓점 클릭 → `도형 완료`
4. `선택·편집` → 사용자 도형 선택 → 꼭짓점 드래그
5. `지명 추가` → 지도 클릭 → 지명 생성
6. `프로젝트 저장` → 현재 작업 파일 저장
7. `프로젝트 불러오기` → 이전 작업 복원
8. `GeoJSON 가져오기` → 외부 공간 데이터를 사용자 도형으로 추가

## 버튼이 작동하는지 확인하는 법

버튼을 누르면 다음 위치에서 상태를 확인할 수 있습니다.

- 상단 중앙: `준비 / 완료 / 오류`
- 지도 아래: `현재 도구`
- 하단 상태바: `마지막 동작`
- 지속 모드: 선택된 버튼 자체가 강조됨

예를 들어 `폴리곤`을 누르면 버튼이 활성화되고 `현재 도구: 폴리곤 그리기`가 표시됩니다.

## 현재 한계

이번 수정의 목표는 **기본 지구본·국경·엔진의 완전 내장**입니다. 아래 기능은 아직 후속 개발 대상입니다.

- 내장 국가 경계 자체의 꼭짓점 직접 편집
- 서로 맞닿은 국가의 공유 국경(shared border) 동시 편집
- 국가 폴리곤 분할·병합
- 영역 선택 후 다른 국가로 영토 양도
- 브러시 기반 초세밀 민족·언어·종교 분포
- 수십만~수백만 개 셀의 고성능 렌더링
- 타임라인과 연도별 국경
- 국가운영 시뮬레이션 세이브 연동

현재는 **사용자가 새로 만든 폴리곤과 선**의 꼭짓점 편집이 가능합니다. 기본 177개 국가 폴리곤은 선택·색칠·속성 수정 대상입니다.
